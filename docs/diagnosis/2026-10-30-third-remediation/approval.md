# 待批准的真实模型实验（本次未执行）

拟用 DeepSeek 官方 OpenAI-compatible 接口，模型名 `deepseek-flash`，目前公开版本 DeepSeek-V4.1-Flash-1017。2026-10-30 只读核对 [官方模型与定价](https://api-docs.deepseek.com/quick_start/pricing/)：每百万输入 cache miss $0.15（非高峰）/$0.30（高峰），cache hit $0.003/$0.006，输出 $0.60/$1.20。别名可移动，实际调用前需复核公开版本并冻结返回版本；版本或价格改变则停止，不擅自换模型。禁用服务端搜索/Fetch 与 thinking；不请求真实用户/业务数据。

|阶段|设计|任务尝试数|
|---|---|---:|
|A 开发预检|13 个 development × 两臂 × 1 次|26|
|B 候选生成|只看 development，生成两个不同候选；两个受限请求|0（另计 2 个请求）|
|B 筛选|12 个 selection × 基线及两个候选 × 3 次；运行时固定|108|
|A 最终盲测|11 个 blind × 两臂 × 5 次|110|
|B 最终盲测|同 11 个 blind × 固定基线及唯一入选候选 × 5 次|110|
|总上限|354 个尝试，两个生成请求；不因失败补跑|354|

候选筛选预规则：优先任务级 verified workflow completion；不得增加错误完成、错误拒绝或人工依赖；并列时按全任务已知 Token 总量选，缺资源记录时不得宣布成本获胜；无候选满足就拒绝候选，仍报告筛选成本。开发/选择结束后必须再次冻结候选、源码与配置，才解封 blind 输入；评分答案始终只在外部控制器。A 与 B 的同任务重复为相关观测，分别估计两种干预，不合并成 220 个独立任务。

每尝试上限：12 个模型请求、单请求输入 8192 / 输出 2048 Token、累计输入+输出+缓存读写在 60000 后不再派发；最后一次请求最多超出 10240，因此严格记账上限 70240。候选生成每请求 8192 输入+2048 输出。全实验理论上限 24,885,440 Token，批准限额 **2500 万 Token、4250 个请求、18 美元**，任一将被突破即停止。输出最多 8,704,000 Token，其余至多 16,181,440 输入；按高峰 cache miss 保守估计模型费用不超过 **$15.30**（不含税/汇率，不计缓存优惠）。若平均每尝试输入 8000、输出 2000，含生成预计约 **$0.85–$1.71**；这是预算假设，不是测量值。单价/用量/缓存写收费不明时费用未知，暂停而不是当零。失败、超时、缺记录仍占分母和已发生预算；无自动补跑。

运行参数：同一模型版本、temperature=0.2、maxTokens=2048、thinking 关闭、无隐藏模型重试；每任务重复配对并交错 AB/BA，记录供应商是否支持 seed，不支持则仅使用配对标签。最大并发 1，业务每尝试最多 4 个目标轮次、32 次工具调用、180 秒；外部控制器 240 秒，崩溃注入至多一次恢复，全部请求跨 boots 累计计费。暂停/确认由预注册模拟创建者脚本执行并计人工命令，不让模型代人确认。

沙箱：批准后先构建并冻结指定镜像 digest，再进行无模型逃逸/挂载检查；独立临时 Docker 容器，每尝试只挂任务目录到 `/workspace`，非 root、只读根、network=none、drop ALL capabilities、no-new-privileges、1 CPU/512 MiB/64 PIDs、受限 tmpfs，无 Docker socket、宿主仓库、答案或凭证挂载。有界文件与 mock effect 协议由控制器提供，模型不获得宿主 bash。模型 API 在容器外代理，凭证仅来自用户明确指定的位置；只读取获批凭证，不扫描其他位置。真实 Slack/Feishu、任意 bash 幂等性、生产业务副作用不在审批范围。
