# LightClaw 诊断与最小修复（2026-10-21）

本轮确认了可重复的机制缺陷，完成开关和局部修复，但尚未完成用户要求的真实模型完整消融。现有真实结果均来自开始工作前已有记录；不把它们列成本轮新跑结果。当前版本的真实模型运行数为0，原始pi/mom端到端运行数为0。

## 一、证据、流程与实验边界

`source-before.json`、`before/`、`status-before.txt`固定本轮起点；工作区已有大量未提交代码及三批同日实验。重新计算42+33+119=194个历史归档文件哈希，全数一致。`analyze.py`只读历史原始数据，另写本目录派生结果，不改历史脚本、数据、检查器或阈值。十份完整session的人工分析见 `failure-review.zh-CN.md`，全部失败的索引/摘录见 `failure-annotations.jsonl`。

实际路径：FeishuBot/SlackBot接收平台事件 → `enqueueChatEvent` / `ChannelQueue`按频道串行 → main的handler取得`IdleResourceCache`频道状态 → `handleGoalCommand`处理真实用户控制 → `AgentRunner.run`加载session、memory、用户、技能并组装system prompt → `AgentSession.prompt` / pi-agent-core内层工具循环 → `beforeToolCall`预留预算 → executor运行工具 → toolResult进入会话 → 模型继续或结束 → main记账、`GoalStore.recordCycle`判断继续/熔断 → 长目标生成continuationEvent再运行。

完成申请走`tools/goal.ts` → `GoalStore.requestCompletion` → `verifyGoalCompletion`文件规则/命令 → 再核对产物快照及目标控制版本 → 自动完成、等待创建者确认或拒绝。容器由`sandbox.ts`映射/workspace并通过docker exec使用；CLI默认host，Docker是显式选择。鉴权在工作区外。审计是main的`appendAuditEvent`，评估器是另一路直接调用Runner；后者**不经过平台队列、main目标续跑或TTL调度**。因此现有短文件任务评估不能测到所有七领域。

本地认证两个auth.json均为空对象；没有重用未知用途的其他provider token。经权限提升的只读检查，Docker29.7.2及原镜像`lightclaw-sandbox:local`存在，Docker可访问限制已解决；有效原模型凭证仍缺失。没有付费API、外部平台投递、构建或发布。

## 二、先看噪声

历史两个对照块的Agent源码SHA一致，12个final任务完全一致，但Node版本不同（旧块22，后块24），且按时间分块，没有固定请求种子。因此它们不能冒充“同一完整配置至少5次”的正式噪声实验。每块仅3次，用户要求仍缺2次以上。

同源码任务的六轮探索性统计：严格成功率83.3%、91.7%、83.3%、91.7%、75%、83.3%；均值84.72%，样本方差0.003935、标准差6.273个百分点、极差16.667个百分点。每任务总Token均值11260.68，六轮均值标准差442.18，极差1032.42（约9.17%）；每任务耗时均值3993.57ms，标准差180.72ms，极差448ms。原始逐轮值及分块统计在`summary.json`。

这只是已有数据的波动描述，不作新版本晋升阈值。候选成功率下降8.33个百分点，任务成簇bootstrap95%区间[-25.00,+5.56]个百分点，跨0，不确认稳定退化；更不能声称提升。历史精简修复成功率增加11.11个百分点，也低于探索性六轮极差，不能仅凭该点估计认定泛化提质。Token下降34.57%超出观察到的Token波动，且产物正确率保持36/36，支持保留已有提示词简化；仍不是新版本验证。

## 四、提示词组成、上下文与假设判断

`prompt-composition.jsonl`精确拆解462次真实历史最终集请求：各system部分字符/UTF-8字节、工具schema字符、消息数、总消息字符。真实Token使用每条assistant的usage，包含input/cacheRead/cacheWrite/output。供应商未提供分段计数，也无该模型官方tokenizer；分段token记null，不用字符/4伪装精确Token。历史任务没有目标续跑，无法识别“N轮之后质量下降”的阈值。

| 假设 | 判定与依据 |
|---|---|
| 提示词过长或冲突 | 在既有短文件样本上证实成本负担/路径冲突。单因素slim9次总Token11782.7→7627.3，但耗时4.190→4.363秒，不证实时间收益；cwd两处矛盾由真实请求及错误验证。短提示词不是已证实的推理质量改善。 |
| 验收误拒绝/拒绝不 actionable | 机制层证实。本轮每种机制每组5次，进展记账导致正确产物验证过期0/5→5/5正确提交；拒绝文本包含路径和条件0/5→5/5。无生产误拒绝率。 |
| 自动继续使上下文膨胀并在N轮降质 | 未验证。continuation作为新user消息会进入context，但无激活目标循环的多轮真实模型样本，不能确定N或质量因果。 |
| 熔断过早结束仍有进展的任务 | 生产层未验证。已证实只依赖模型进展报告，重复同样报告也递增版本；本轮去重正确行为0/5→5/5。仍缺研究/搜索型任务客观进展信号，不新增未经验证的“工具调用数=进展”启发式。 |
| 沙箱阻碍合理工具 | 证实固定镜像缺file，以及环境指令/cwd不一致。没有证据证明合理Git、安装依赖或普通写入被安全策略阻断；不能笼统归咎沙箱。 |
| 淘汰/恢复丢失信息 | 对既有faux churn样本否定：每组3进程、8448任务的传入历史消息数和文本字符一致。不能推及真实长期压缩/崩溃恢复；重建代价已观察到。 |
| 队列/TTL实际负载影响结果 | 合成突发负载证实影响接纳率，未验证实际生产负载。9600提交，容量组仅1440完成、8160拒绝；期限组960完成、8640过期。共同完成任务没有可靠等待收益，P95下降不是等工作量提速。缓存回收降低heap增量，却未证实进程RSS同比降低。 |
| 提示词候选过拟合或收益在噪声内 | 本候选无提质证据，训练门禁本就拒绝，不能断言“训练大涨、留出无益”这一特定模式。36次候选产物36/36不变，Token+9.91%，严格成功31/36→28/36区间跨0。新回归证实旧策略能错误晋升噪声内或仅训练获益的合成报告。 |

## 五、独立开关与消融矩阵

环境变量统一 `LIGHTCLAW_FEATURE_<NAME>=true|false`，拒绝拼错的值；省略保持已有默认。不要把全部关闭称原始mom。关闭基础设施明确选择host执行，只可用于可信工作区，不把这一模式用于不可信任务。

| NAME | false的执行边界 |
|---|---|
| GOALS | main不处理目标命令、不恢复或续跑；Runner不注入目标提示或目标工具；停用状态读取。 |
| ACCEPTANCE | 与目标开关独立；完成记录为self_reported且report为inconclusive，不生成虚假passed检查，用户可见“未验证”。 |
| FEISHU | 选择Slack路径并要求Slack凭证；不是在本地伪造飞书投递。 |
| CONTROLS | 关闭新增每轮时间/工具/Token及目标轮数/失败/停滞熔断，保留取消、统计和工具自身超时。外部评估仍应设置总进程超时。 |
| SCHEDULING | 同频道FIFO保留；关闭待处理容量/期限、空闲TTL和LRU；不设置超大阈值冒充关闭。 |
| OPTIMIZATION | 忽略候选追加行为指令，优化入口在模型调用前拒绝；外部独立检查器仍可评价系统。 |

## 六、本轮修复、取舍与最终对照

按证据强度、修复工作量和风险排序：①可操作的验收反馈与争议渠道；②用独立验证控制版本区分进展记账和真正取消/恢复/完成，继续校验产物；③优化器要求至少5次不同请求种子、收益严格超过实测基线极差及最小效应量、留出集质量也获益、逐用例均分不得退化；④重复进展去重；⑤七开关便于后续消融。另用虚构凭证复现审计detail原样泄露的问题，补常见凭证脱敏和长度上限，不声称能识别任意秘密。

新增 `/goal dispute <attemptId> <原因>`：仅真实平台上的创建者可记录，写入控制目录verification-disputes.jsonl；不篡改原验收、检查器或状态。独立验证版本允许进展/轮次记账，暂停/恢复/替换仍拒绝旧申请。5场景×2组×5重复=50条新机制运行，完整记录见mechanism-runs.jsonl。三个缺陷正确行为各0/5→5/5，暂停恢复和产物变更保护均5/5→5/5。确定性场景观测方差0，不解释为LLM噪声为0。

原有长教程移到按需指南、cwd与缺失命令提示，是本轮起点已有修复。保留它们有历史成本证据；未将其伪装成本轮新成果。自动候选没有默认推广路径，本轮进一步阻止噪声内/仅训练获益的晋升。不删除Feishu、验收或缓存：对应产品功能/资源治理存在明确用途，尚无完整任务消融足以支持永久删除。队列与TTL保留可关闭选项，不再表述为普遍加速。
