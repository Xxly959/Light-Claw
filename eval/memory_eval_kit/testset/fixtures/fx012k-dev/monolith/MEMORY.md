# 全局记忆（MEMORY.md）

- 【规则】文件名一律使用小写字母加连字符，不要空格、下划线或大写。
- 【规则】回复中不要使用项目符号列表（不要以“- ”或“• ”开头分点）。
- 【规则】日期一律写成 YYYY-MM-DD 格式（例如 2026-03-05），不要用“x年x月x日”的写法。
- 【规则】时间一律使用 24 小时制（如 15:30），不要写“下午三点半”这类说法。
- 【规则】金额一律以“万元”为单位表述，不要写成带千分位的元。
- 【约定】代码评审至少需要 1 人通过才能合并。
- 【约定】新人入职第一周需完成安全培训。
- 【约定】线上变更窗口为周二、周四晚间。
- 【约定】报销单需在发生后 30 天内提交。
