# S2 改动记录

每个开关独立关闭时从同一 facts.json 重建布局。S2 关闭全部开关仍属于 S2 的布局器，S1 基线使用题包原生布局及 S1 Runner。dev 用于选择，test 只在冻结后评测。

## i1 常驻规则

- 假设：隐藏在笔记里的长期规则无法从普通请求触发读取。
- 改动：规则先在所属范围的索引内联。关闭时遵循事实元数据的原始内联或笔记位置。
- 预期收益：提高隐式规则遵循率。
- 预期风险：常驻规则增多，可能增加 token 或与用户当前请求冲突。
- 实测结果：待 dev。

## i2 优先级与双预算

- 假设：按追加顺序截断会首先丢失尾部事实和更正。
- 改动：规则优先，其次更正、热点和路由。索引受 1,800 字符和 4,096 字节上限约束。放不下的事实转入笔记，索引显示省略数量和完整目录链接。
- 预期收益：缩小常驻内容并减少位置效应。
- 预期风险：目录层可能增加一轮读取。规则超预算时显式拒绝渲染，需要操作者整理规则。
- 实测结果：离线构造用例验证两个预算和全部事实可达，模型指标待 dev。

## i3 更正链单一真值

- 假设：旧值与更正同时出现时，可能使用过时值。
- 改动：用显式 supersedes 验证同范围、实体、属性的更正链。可检索布局只含链尾值和更新日期。原 facts.json 保留历史，旧 ID 指向当前可读文件。
- 预期收益：减少陈旧值命中与重复内容。
- 预期风险：需要问历史值的任务应读取独立历史档案。分叉、循环或不明目标拒绝渲染，避免擅自选择真值。
- 实测结果：离线验证多次更正、旧值剔除和非法更正，模型指标待 dev。

## i9 紧凑主题笔记

- 假设：粗粒度笔记会把同一主题的无关实体也送进后续上下文。
- 改动：按主题与实体分文件，首行描述实体，路径使用稳定名称和摘要。两版都可用同一个受限检索工具，避免把工具差异混进布局对照。
- 预期收益：减少单次 read 回传和错读其他实体的可能。
- 预期风险：文件和路由更多，跨实体问题可能需要多次读取。
- 实测结果：离线用例确认实体分离及独立可读，模型指标待 dev。

## i6 确定性布局检查

- 假设：人工维护的索引可能超过预算，或让笔记失去入口。
- 改动：评测可开关执行离线 lint。检查 4 KiB、悬空或越界链接、不可达笔记、重复行、冲突标记和事实映射。仅报告问题。
- 预期收益：在模型调用前发现结构退化。
- 预期风险：不能判断措辞不同但含义相同的冲突；无语义去重。
- 实测结果：构造用例验证失败分类与目录可达性。此开关不改模型输入，不预期改变准确率。
