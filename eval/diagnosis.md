## 其他边界

- **宿主生成指南的链接写入，高，源码可证。** S0 和 S1 均通过普通 `writeFile` 重写频道目录里的 `.lightclaw-guide.md`。拥有频道目录写权限的进程若事先建立 `.lightclaw-guide.md -> ../MEMORY.md`，宿主会按宿主路径解析链接，可能把全局索引覆盖成生成的指南。攻击者需要能在频道目录放置链接，宿主需要对目标有写权限。S1 对索引文件的 `O_NOFOLLOW` 仅作用于该读取，目录检查也只检查频道目录项。诊断未运行覆盖操作。 [指南写入](../packages/lightclaw/src/agent.ts#L1290-L1294) · [索引读取](../packages/lightclaw/src/agent.ts#L201-L229) · [频道目录检查](../packages/lightclaw/src/agent.ts#L1247-L1252)
- **完整行边界与解码失败，中，离线复现。** 恰好 4,096 字节且没有末尾换行的一行可见，仅追加一个 LF 就会触发超限并隐藏整行。一个合法规则后紧跟非法 UTF-8 时，若解码范围包含坏字节，该份索引整段省略，只有警告日志。 [完整行扫描和解码](../packages/lightclaw/src/agent.ts#L214-L228)
- **大型笔记的按需读取，中，源码可证。** 工具先运行 `wc`，再用 `cat` 或 `tail` 取内容，用户指定的 `limit` 在命令返回后才生效。命令输出超过 10 MiB 时，执行器返回尾部缓冲，并尝试另存完整输出。因此回查超大文件时可能丢失请求的头部，后续工具提示仍按原请求行号解释尾部。此路径没有做实机复现。 [读取实现](../packages/lightclaw/src/tools/read.ts#L68-L109) · [执行器捕获上限](../packages/lightclaw/src/sandbox.ts#L258-L266) · [尾部捕获](../packages/lightclaw/src/sandbox.ts#L347-L367)

## 离线复现

从仓库根目录运行下方命令。本次复现使用 Node v22.23.0。

```sh
rtk proxy node --disable-warning=ExperimentalWarning eval/harness/diagnose_offline.mjs
```

脚本从 Git 提取基线函数，在 VM 中执行真实的读取、提示和编辑实现。文件、描述符和共享写交错均用合成内存替身。脚本只读取源码，退出码为 0 时代表断言全部通过。未启动 LightClaw、容器、平台或模型。若检出的仓库缺少 S1 快照，可把内容匹配该 blob 的 `agent.ts` 路径作为第一个参数传入。 [脚本](harness/diagnose_offline.mjs)

将常用且需要自动生效的规则放在可见索引（i1），优先保留规则和有效索引项并对溢出给出线索（i2），按事实 ID 维护修订链和单一生效版本（i3），用离线 lint 检查超限、破链和冲突（i6），补充路径与回查提示（i7），将详细内容拆成可定位的短笔记并提供清晰路由（i9）。i4 如纳入实现，目标是约束宿主生成指南的写入路径。共享路径可写时的并发编辑语义、全局可见性、模型行为、token 与成本均需分别验证。
